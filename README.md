## ที่มาและความสำคัญ

เงินเดือนเป็นปัจจัยสำคัญในการตัดสินใจเลือกอาชีพและสะท้อนความเป็นธรรมของค่าตอบแทนในสายงานไอที เงินเดือนในสายงานนี้แตกต่างกันมากตามระดับตำแหน่ง ประสบการณ์ เมืองที่ทำงาน และเพศ แต่ข้อมูลเงินเดือนมักไม่เปิดเผย ทำให้ประเมินระดับเงินเดือนที่เหมาะสมได้ยาก โครงงานนี้จึงใช้ Python วิเคราะห์ด้วยสถิติเชิงพรรณนาและกราฟ เพื่อให้เห็นแนวโน้มและความสัมพันธ์ระหว่างปัจจัยต่าง ๆ กับเงินเดือน

## วัตถุประสงค์

1. เพื่อเปรียบเทียบเงินเดือนเฉลี่ยต่อปีระหว่างระดับตำแหน่ง (Seniority) เมืองที่ทำงาน และเพศ
2. เพื่อวิเคราะห์ความสัมพันธ์ระหว่างประสบการณ์ทำงานรวม อายุ กับเงินเดือนต่อปี
3. เพื่อระบุระดับตำแหน่งที่มีเงินเดือนเฉลี่ยสูงสุด/ต่ำสุด และตรวจหาค่าผิดปกติของเงินเดือนด้วยกฎ 1.5×IQR

## คำถามของโครงงาน

| ข้อ | คำถาม | ตอบด้วย |
| --- | --- | --- |
| 1 | ระดับตำแหน่ง เมืองที่ทำงาน และเพศ ที่แตกต่างกัน ส่งผลต่อเงินเดือนเฉลี่ยต่อปีหรือไม่ อย่างไร | ค่าเฉลี่ย, กราฟแท่ง, แผนภาพกล่อง |
| 2 | ประสบการณ์ทำงานรวมและอายุมีความสัมพันธ์กับเงินเดือนต่อปีอย่างไร | กราฟการกระจาย (Scatter plot), ค่าสัมประสิทธิ์สหสัมพันธ์ |
| 3 | ระดับตำแหน่งใดมีเงินเดือนเฉลี่ยสูงสุด/ต่ำสุด และมีค่าผิดปกติหรือไม่ | ค่าเฉลี่ย, ส่วนเบี่ยงเบนมาตรฐาน, กฎ 1.5×IQR, กราฟแท่ง |

### พจนานุกรมข้อมูล

คอลัมน์ที่ใช้วิเคราะห์ใน `salary_clean.csv` (1,186 แถว)

| คอลัมน์ | คำอธิบาย | หน่วย | ชนิดข้อมูล | ค่าว่าง |
| --- | --- | --- | --- | ---: |
| `age` | อายุของผู้ตอบแบบสอบถาม | ปี | ตัวเลข | 0 |
| `gender` | เพศ: Male, Female, Diverse (Diverse มี 2 รายการ) | - | กลุ่ม | 3 |
| `city` | เมืองที่ทำงาน: Berlin, Munich, Frankfurt, Other | - | กลุ่ม | 0 |
| `seniority` | ระดับตำแหน่ง: Junior, Middle, Senior, Lead, Head, Other | - | กลุ่ม | 0 |
| `exp_total_years` | จำนวนปีของประสบการณ์ทำงานทั้งหมด | ปี | ตัวเลข | 0 |
| `salary_eur` | เงินเดือนรวมก่อนหักภาษีต่อปี ไม่รวมโบนัสและหุ้น (ตัวแปรตามหลัก) | ยูโร (EUR) ต่อปี | ตัวเลข | 0 |

หน่วยของจำนวนเงินทั้งหมดคือยูโร (EUR) และเป็นเงินรวมก่อนหักภาษี (brutto)

คอลัมน์อื่นในไฟล์ เช่น `position` (135 รูปแบบ กรอกเอง), `main_tech`, `bonus_eur`, `vacation_days`, `company_size`, `company_type` ไม่ได้ใช้ในโครงงานนี้

## วิธีดำเนินการ

1. อ่านข้อมูลเข้าโปรแกรม: `pd.read_csv()`
2. ตรวจสอบภาพรวมและชนิดข้อมูล: `df.info()`, `df.shape`, `df.head()`
3. ตรวจและจัดการค่าสูญหายกับข้อมูลซ้ำ: `df.isna().sum()`, `dropna()`, `fillna()`
4. คำนวณค่าเฉลี่ยและส่วนเบี่ยงเบนมาตรฐาน: `df.mean()`, `df.std(ddof=1)`, `df.describe()`
5. คำนวณค่าสถิติแยกตามกลุ่ม: `df.groupby(col).agg()`
6. ตรวจหาค่าผิดปกติด้วยกฎ 1.5 × IQR: `df.quantile()`
7. สร้างกราฟและตีความ: `matplotlib.pyplot`
8. สรุปผลและเขียนรายงาน
